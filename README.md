# Portfolio Kỹ thuật số

Website tĩnh để đăng lên GitHub Pages cho bài tập dự án cá nhân Portfolio.

## Cấu trúc

- `index.html`: trang chính
- `styles.css`: giao diện
- `script.js`: dữ liệu bài tập, gallery ảnh và tương tác
- `assets/docs/`: các file Word bài làm và rubric
- `assets/images/`: ảnh đề bài và ảnh minh chứng tách từ file Word

## Đăng lên GitHub Pages

1. Tạo repository mới trên GitHub, ví dụ `portfolio` hoặc `username.github.io`.
2. Đưa toàn bộ nội dung thư mục này lên repository.
3. Vào `Settings` -> `Pages`.
4. Chọn `Deploy from a branch`, branch `main`, folder `/root`.
5. Lưu lại và chờ GitHub tạo URL.

Nếu repo là `username.github.io`, địa chỉ sẽ là `https://username.github.io/`.
Nếu repo là `portfolio`, địa chỉ thường là `https://username.github.io/portfolio/`.
